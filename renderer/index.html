03

Before you start

  1. 01

    Import the browser session and open both pages. Confirm that each page is signed in.

    Switch each page to Temporary Chat, check personalization, and tick the confirmation below each page.

    Enter one question and press Start automatic debate. The app sends and relays text; press Stop at any time.
