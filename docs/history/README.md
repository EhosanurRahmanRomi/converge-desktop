# Historical documentation

[← Current project](../../README.md) · [Current user guide](../USER_GUIDE.md) · [1.6.5 verification](../VERIFICATION.md)

The neighboring versioned manuals preserve earlier development and verification records at their original relative paths. They document the implementation and evidence available for each named version, including the earlier browser/extension approaches.

These records are historical. UI labels, connection paths, package names and verification scope may have changed. Their tests do not automatically verify 1.6.5, and an earlier draft marked pending or failed should not be read as a current release claim.

Machine-specific paths, account identifiers and private live-session material are excluded or sanitized for publication. Original private recordings, cookie exports, local profiles and raw authenticated traces are not included.

Use the current guides above for installation, operation and development. Current release identities and limits are in the 1.6.5 verification record.
