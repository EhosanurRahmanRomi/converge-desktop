# Converge 1.6.0 verification

Date: 2026-10-02, Asia/Dhaka. Windows x64.

Version 1.6.0 replaces the subdued 1.5 workspace with a brighter animated spiral galaxy, including cosmetic backgrounds inside the two embedded chat pages, and more expressive vector reviewer bots. This record separates visual fixtures, automated app checks, release package checks and authenticated model results. Visual animation does not establish answer quality or trading performance.

The user has requested additional workstation motion, varied expressions, meeting/handoff gestures and more dynamic stars. **1.6.1 is being developed separately.** The 1.6.0 package evidence below is an intermediate version record, not a final-delivery claim for the requested refinement. A later source/package needs its own gates.

## What changed

### Galaxy in the workspace and chat pages

- A bright procedural spiral galaxy, drifting nebula clouds, glowing stars and occasional meteors fill the workspace. The same scene engine decorates the background of each embedded ChatGPT page, so the galaxy is visible inside the chats rather than only in surrounding gutters.
- Conversation surfaces remain dark and translucent; code blocks, composer and menus retain near-opaque dark backgrounds for readability. The decoration sits behind page content, is hidden from accessibility tools and cannot intercept pointer input.
- The page appearance module is restricted to the exact `https://chatgpt.com` origin. Its local test origin is explicitly supplied by the test harness; a different localhost origin receives no decoration.
- The appearance module marks only bounded layout ancestors and does not read message text, replace editors, change upload inputs, alter privacy settings, inspect cookies or control review state. Navigation/disposal removes its canvas, styles, attributes, observers and event listeners.
- WebGL is the primary renderer. A procedural Canvas2D fallback is available when WebGL cannot initialize. There are no remote artwork, font or animation-service dependencies.
- Rendering is bounded: a maximum 30 frames per second in the app shell, 24 in each embedded page, device scale capped at 1.25 and internal scene bounds of 1050 by 720. These are resource caps, not a guarantee of a particular frame rate on every computer.

Production sources: `renderer/galaxy-scene.js`, `renderer/galaxy-scene.css`, `src/browser/page-appearance.js`, `renderer/browser.html`, `renderer/browser.css` and `renderer/browser-app.js`. The isolated page bundle is generated by `scripts/build-page-preload.js`.

### Expressive reviewers and truthful exchange animation

- Shaded vector bots have cyan/violet eyes, beacons, orbital halos, expressive gaze, blinking, floating, hands, thought dots and a scanning document hologram. Their shared deck is **108 px high** at the recorded desktop size; each bot occupies 128 by 108 px.
- Working poses use a **24-second main cycle**. Idle head/gaze and arm poses use **28- and 32-second cycles**, with offset timing between the bots. Idle motion is decorative; it does not claim that a model is generating a response.
- Activity labels and working poses follow the owned draft/review request and actual page activity. The UI does not hardcode a selected model name it cannot read.
- A paper passes once after an actual successful peer submission acknowledgment, in its recorded direction. `lastTransfer` identifies the run, request, candidate, source side, target side and whether files were submitted. Existing successful source-readback acknowledgments remain a compatibility fallback. Busy pages, unsent drafts, same-page rechecks and historical restored events do not manufacture a handoff.
- Errors, stalled work and required native work that is still unverified retain an attention state. Agreement is not presented as proof of 100% correctness or trading profitability.
- The controls remain a sliding overlay. Both chats retain more than 85% combined window width with controls closed; the bottom drawer retains the current action, rounds, output files and native Save controls.

### Motion control

**Pause effects** pauses both the shell scene and embedded-page scenes through a narrow desktop IPC call. The preference is stored only as a local UI setting. System reduced-motion settings and hidden-document state pause decorative motion. Paper animation is canceled when motion is disallowed. WebGL context loss stops rendering; restoration reinitializes it. Disposal stops scheduling and releases graphics resources.

An initialization error introduced while connecting the new scene was caught during focused renderer checks: the effects setup referenced the desktop API before its declaration. The setup now uses the available narrow window interface. The full suite below was run after that repair.

This proves cosmetic isolation for that controlled page structure. It does not establish that every future ChatGPT page layout or provider upload behavior will be unchanged.
